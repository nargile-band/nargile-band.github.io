日本語

「なるぎれ Social Manager」（別名「SM Uploader」、以下「本アプリ」）は、バンド「なるぎれ」が自らの動画を自らの SNS アカウントへ投稿するために使用する、メンバー専用のアプリケーションです。一般の方への提供は行っていません。

1. YouTube API サービスの利用について

本アプリは YouTube API サービスを利用しています。本アプリを利用する場合、YouTube 利用規約および Google プライバシーポリシーが適用されます。

2. 取得する情報

  • YouTube：チャンネルの基本情報（チャンネル名・チャンネル ID）、動画をアップロードする権限
  • Instagram：アカウントの基本情報（ユーザー ID・ユーザー名）、リール動画を投稿する権限
  • TikTok：アカウントの基本情報（open_id・表示名）、動画を下書きとして送る権限（video.upload）

3. 利用目的

取得した情報は、なるぎれのアカウントへ動画を投稿（または下書き送信）すること、および接続状態を確認することにのみ使用します。広告やその他の目的には使用しません。

4. 保存と管理

認証に必要な情報（アクセストークン等）は、本アプリを実行するメンバーのコンピューター内（macOS のキーチェーン）にのみ保存し、外部のサーバーには送信・保存しません。投稿のため、動画は各サービスに送信されます。

5. 第三者への提供

取得した情報を第三者に提供・販売することはありません。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによる Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（Limited Use の要件を含む）に従います。

7. アクセス権の取り消し

本アプリに与えたアクセス権は、各サービスの設定からいつでも取り消すことができます（Google：https://myaccount.google.com/permissions）。

8. お問い合わせ

nargile.band@gmail.com

English

"Narugire Social Manager" (also "SM Uploader"; the "App") is a private application used only by the members of the band "なるぎれ (Narugire)" to post their own videos to their own social media accounts. It is not offered to the public.

  1. YouTube API Services. The App uses YouTube API Services. By using the App, you are subject to the YouTube Terms of Service and the Google Privacy Policy.
  2. Information accessed. Through each platform's official authorization: YouTube channel basic info (name, ID) and permission to upload videos; Instagram account basic info (user ID, username) and permission to publish Reels; TikTok account basic info (open_id, display name) and permission to upload videos as drafts (video.upload).
  3. Purpose. Used only to post (or send as drafts) videos to the band's own accounts and to check the connection status. Not used for advertising or any other purpose.
  4. Storage. Access tokens are stored only on the member's own computer (macOS Keychain) and are never sent to or stored on any other server. Videos are sent to each platform for posting.
  5. Sharing. We do not share or sell any information to third parties.
  6. Google API Services User Data Policy. The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  7. Revoking access. Access can be revoked at any time from each platform's settings (Google: https://myaccount.google.com/permissions).
  8. Contact: nargile.band@gmail.com
